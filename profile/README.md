# 🧠 About

This organization contains my production systems, SaaS platforms, business applications, and infrastructure experiments.

The ecosystem is built around:

- Full-stack web applications
- AI-powered SaaS tools
- Hybrid Node.js + PHP architecture
- CI/CD automation with GitHub Actions
- VPS production deployment
- Multi-service reverse proxy infrastructure
- Real-world business systems

All applications are actively deployed on production infrastructure using Ubuntu VPS, Nginx, PM2, MySQL, and GitHub-based deployment pipelines.

# ⚙️ Deployment Architecture

```text
GitHub Push
    ↓
GitHub Actions
    ↓
VPS Deployment Trigger
    ↓
git pull
    ↓
Install Dependencies
    ↓
Build Frontend (if needed)
    ↓
PM2 Restart / Start
    ↓
Nginx Reverse Proxy
```
